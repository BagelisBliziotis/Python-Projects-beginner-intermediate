# 06 - Reeborg's World

*Description
5 robot navigation challenges in Reeborg’s World.  
Started with basic hurdle jumping and progressively built up to solving a complex final maze using custom functions and logical decision-making.

- *Hurdle 1 – Simple wall jumping with repeated code  
- *Hurdle 2 – Variable hurdle heights  
- *Hurdle 3 – More complex hurdle patterns  
- *Hurdle 4 – Advanced hurdle navigation requiring better logic  
- *Final Maze – Complete maze-solving algorithm with dynamic decisions

&What I Learned
- How to define and use my own functions (def) to avoid code repetition  
- Building modular reusable code  
- Combining functions with while loops, if/elif/else conditions    
- Debugging robot behavior logically instead of guessing
