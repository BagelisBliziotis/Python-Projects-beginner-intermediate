# 12 - Number Guessing Game

*Description
A fun number guessing game where the computer picks a random number between 1 and 100.
You choose easy (10 lives) or hard (5 lives) mode and try to guess it before you run out of attempts.

## What I Learned
- Using while loops with a lives/attempts counter
- break statement to exit the loop when the player wins
- if/elif chains to handle "Too High" / "Too Low" feedback
- Input validation for difficulty level
