# 05 - PyPassword Generator

*Description
A password generator that asks the user how many letters, symbols, and numbers they want, then creates a strong random password using lists and shuffling.

*What I Learned
- Working  again with lists and the random module (random.choice() and for the first time random.shuffle() )
- Using for loops to build a list
- Converting a list back into a string
- Creating an easier version(without shuffling the code) and then thinking how to upgrade it
