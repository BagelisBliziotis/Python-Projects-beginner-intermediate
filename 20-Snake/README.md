# 21 - Snake Game

## Description
A complete classic Snake game built with Object-Oriented Programming.
Control the snake with the arrow keys, eat the red food to grow longer and increase your score
while avoiding collisions with the walls or your own tail.

## What I Learned
- Building a full game using multiple classes (Snake, food, Scoreboard)
- Object-Oriented Programming principles (inheritance, encapsulation, composition)
- Real-time keyboard controls with event listeners
- Collision detection (wall, self-collision, food)
- Managing game state and updating the score dynamically
