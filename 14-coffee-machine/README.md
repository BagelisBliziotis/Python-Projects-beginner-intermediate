# 14 - Coffee Machine

*Description
A realistic coffee machine simulator. Users can order espresso, latte or cappuccino
pay with coins, receive change, view a resource report, and the machine automatically turns off when resources run low.

*What I Learned
- Importing and using a separate data file (menu_list.py)
- Creating multiple helper functions for different tasks
- Resource management and checking with dictionaries
- Coin calculation and change handling
- while True loop control with break statements
- Input validation and error handling
-First time using try,except
