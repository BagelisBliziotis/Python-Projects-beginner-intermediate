# 15 - Coffee Machine (OOP)

*Description
Object-Oriented version of the Coffee Machine.
Uses separate classes (Menu, CoffeeMaker,MoneyMachine) for a clean, modular design. 
Users can order drinks, pay with coins, view reports, and turn off the machine.

*What I Learned
- Object-Oriented Programming (OOP) basics
- Importing and using custom classes
- Working with objects and their methods (find_drink(), is_resource_sufficient(), make_payment(), make_coffee())
- Cleaner code structure by separating concerns (menu, resources, money)
