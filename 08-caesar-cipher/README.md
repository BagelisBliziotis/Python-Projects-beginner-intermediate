# 08 - Caesar Cipher

*Description
I implemented a full Caesar Cipher program that can both encode and decode messages by shifting letters in the alphabet.  
The program also includes a loop so the user can encrypt/decrypt multiple messages in one run.

*Features
- Separate art.py file with the logo
- Handles uppercase/lowercase conversion
- Preserves spaces and symbols
- Go again option (yes/no)
- Clean modular function  caesar()

*What I Learned
- Creating and using my own functions with multiple parameters
- String manipulation and list indexing
- Modulo operator (%) for alphabet wrapping. One of the most usefull operators i have learned
- Building a small interactive program with user input loops
