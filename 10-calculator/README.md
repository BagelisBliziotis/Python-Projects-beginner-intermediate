*10 - Calculator

*Description
I built a fully functional calculator that supports addition, subtraction, multiplication and division.  
The user can continue calculating with the previous result or start a fresh new calculation.

*Features
- Uses a dictionary of functions for operators
- Clean while True loop for repeated calculations
- Option to continue with result (y) or start new (n)
- ASCII art logo on new calculations
- Simple screen clear using new lines

*What I Learned
- Creating multiple functions and storing them in a dictionary
- Using functions as values with outputs in a dictionary
- Building a continuous calculator with user choice
