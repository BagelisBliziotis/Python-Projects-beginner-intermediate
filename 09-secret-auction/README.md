# 09 - Secret Auction

*Description
A blind/secret auction program where multiple bidders can secretly submit their names and bids.
At the end the program announces the highest bidder as the winner.

*Features
- Repeatedly collects bidder name and bid amount
- Clears the console between bidders to keep bids secret
- Stores all bids in a dictionary
- Finds and announces the winner with the highest bid

*What I Learned
- Using Python dictionaries to store and retrieve key-value pairs (name: bid)
- Controlling a while loop with a boolean flag until bidding ends (like my previous project)
- Finding the maximum value in a dictionary by iteration
- Screen-clearing technique using print("\n" * 100)
