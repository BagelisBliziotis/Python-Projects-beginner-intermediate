# 04 - Rock Paper Scissors
*Description

A classic Rock Paper Scissors game against the computer using ASCII art. 
Choose 0, 1 or 2  the computer picks randomly and the game tells you if you win, lose, or draw.

*What I Learned
- Importing and using the random module (random.randint())
- Storing ASCII art inside a list
- Complex if/elif/else chains for game logic
- Using a progress flag for input validation
