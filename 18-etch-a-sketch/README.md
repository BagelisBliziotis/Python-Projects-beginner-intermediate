# 18 - Etch-A-Sketch

*Description
A digital Etch-A-Sketch using Python Turtle graphics. Control the turtle with keyboard keys:
- **W** = Move Forward
- **S** = Move Backward
- **A** = Turn Left
- **D** = Turn Right
- **C** = Clear screen

*What I Learned
- Event listeners with screen.onkey() and screen.listen()
- Creating functions for keyboard controls
- Using the turtle module for interactive graphics
- Screen resetting and turtle movement control
