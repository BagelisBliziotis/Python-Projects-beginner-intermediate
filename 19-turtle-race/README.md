# 19 - Turtle Race

*Description
A fun Turtle Race betting game. Six turtles of different colors race to the finish line.
You place a bet on which color will win before the race starts.

*What I Learned
- Creating multiple Turtle objects in a list
- Using screen.textinput() for user betting
- Event-driven animation with a while loop
- Random movement for each turtle
- Detecting the winner by checking x-coordinate
