# 17 - Quiz Project

*Description
A fully functional quiz game built with Object-Oriented Programming. The program loads a list of questions, asks them one by one, keeps track of the score, and gives instant feedback after each answer.

*What I Learned
- Object-Oriented Programming (OOP) in practice
- Creating and using multiple classes (`Question`, `QuizBrain`)
- Working with external data (question list)
- Managing game state (score, current question number)
- Clean separation of concerns using classes
