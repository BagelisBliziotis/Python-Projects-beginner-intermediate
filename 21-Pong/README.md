# 22 - Pong Game

## Description
A fully functional two-player Pong game built with Object-Oriented Programming and the Turtle module. 
Players control the paddles with keyboard keys. First to 10 points wins!

## What I Learned
- Advanced Object-Oriented Programming with multiple classes (`Paddle`, `Ball`, `Scoreboard`)
- Real-time keyboard controls using event listeners
- Collision detection between ball and paddles/walls
- Score tracking and game-over logic
- Screen boundary limits and movement restrictions

## Extra Features I Added
- **Paddles cannot move outside the screen** (added boundary checks so paddles stay fully visible)
- **Ball cannot double-bounce on the same paddle** (prevented instant double hits and buggy gameplay)
