11 - Blackjack

*Description A complete Blackjack game against the computer. You can hit or stand, the dealer plays automatically Aces are handled (11 -> 1 when you bust), and you can play multiple rounds in one session.

*What I Learned

Working with lists to store and update player and computer cards
Using the random module (random.choice()) to deal cards
Building complex while loops for player turns and automatic dealer logic
Using conditional logic (if/elif/else) to determine win, lose, or draw
**Used the break statement for the first time to cleanly exit loops when the player stands or when the game ends
Handling special game rules like Ace conversion when the score goes over 21
