# 07 - Hangman

*Description
I built my own complete Hangman game from scratch differently compare to the courses instructor.  
The player guesses letters to reveal a hidden word. Wrong guesses cost lives. Game ends with win or loss.

*Features
- Random word selection from a large list (90+ words)
- ASCII art logo and hangman stages
- Live display of current word with underscores
- Lives counter (6 lives)
- Prevents guessing the same letter twice
- Clean win/lose messages

*Files
- main.py  Main game logic
- hangman_art.py  Logo and hangman stages
- hangman_words.py  Word list

*What I Learned
- Working with multiple Python files (import)
- String manipulation and list indexing
- Complex while loops with multiple conditions
- Logic for tracking guessed letters and lives
- Building a full game with user interaction
