# 18 - Hirst Painting

*Description
A recreation of Damien Hirst’s famous spot paintings using Python’s Turtle graphics.
The program generates a 10×10 grid of randomly colored dots.

*What I Learned
- First time downloading and installing an external Python package (colorgram) using pip
- Extracting the 30 most dominant colors from an image with colorgram.extract() (the code is commented out at the top of main.py)
- Converting color data into RGB tuples and storing them in a list
- Using the turtle module to create graphical art (Turtle, Screen,dot(), penup()/pendown())
- Creating a grid pattern with nested for loops
- Random color selection from a predefined list
