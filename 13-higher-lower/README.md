# 14 - Higher Lower Game

*Description
A fully functional Higher Lower game based on real Instagram follower counts.
Compare two accounts side-by-side, guess which one has more followers
and try to keep your streak alive as long as possible. 
The winner of each round automatically becomes the next "A".

*What I Learned
- Working with external data stored as a list of dictionaries (game_data.data)
- Creating a reusable function that returns multiple values (winner + index)
- Maintaining game state across rounds by carrying over the winning account
- Using while loops with a flag to control game flow
- Random selection while preventing duplicate comparisons
- Clean separation of game logic using functions
